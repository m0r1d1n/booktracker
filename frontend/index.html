Paste one ISBN per line (ISBN-10 or ISBN-13). Metadata and cover art are fetched automatically from Open Library / Google Books.

Upload a CSV/TSV export from your previous tracker (Title, Author, ISBN, Publisher, Date Read, Shelves, tags, owned, dropped_dates, currently_reading, etc. — columns are matched by name, extras are ignored). Rows whose ISBN already matches a book in your library will update that book's status, dates, rating, and tags instead of duplicating it. If you re-upload a copy of this app's own Export library to CSV file (e.g. after editing statuses or dates in a spreadsheet), it's auto-detected and matched by ID instead — safer and more precise than the ISBN/title guessing used for third-party files.

⚠ If you edit the exported CSV in Excel or Google Sheets, format the ISBN column as Text before saving — otherwise the spreadsheet will silently convert 13-digit ISBNs into scientific notation (e.g. 9.78045E+12), which loses the original digits permanently. This app detects and ignores mangled ISBNs on import rather than saving the corrupted value, but the fix is easiest done in the spreadsheet itself.
